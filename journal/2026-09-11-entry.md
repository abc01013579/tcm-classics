shuiming…Ubuntu CLI 取代vs code terminal 的确很棒，给视觉一个畅展的空间.

cc…在 VS Code 里 在独立 CLI 里
视觉被分割成多个小区域 视觉空间完整
注意力被多个面板争夺 注意力集中在一件事上
需要“切换”到终端 终端本身就是主场
输出被限制在狭小窗口 输出可以自由舒展

shuiming…是不是大多数developers 都是这么弄的

cc…屏幕 常见用途 对应你的设置
左屏 文档、浏览器、参考、聊天（Slack/Discord） YouTube / PDF
中屏 主编辑器（VS Code / Vim） VS Code + CC + Copilot
右屏 终端 / 运行 / 监控 / 测试 Ubuntu CLI
