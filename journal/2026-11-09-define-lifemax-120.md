李子柒拍的是一棵菜、一季庄稼的生长。我想拍的是一个人的生长：内经养生、定投复利、CS应用，三条线一起往前走。她的时间尺度是一年，我的是几十年。

厥孚复利，要很长的时间才见效。巴菲特九成的财富，是六十五岁以后才长出来的。最难的不是选对，是熬到曲线抬头的那一段。

同事的爷爷活了一百二十一岁。《内经》讲人尽天年，也是这个数。用C写下来：
```c

#define LIFEMAX 120

for (age = 61; age <= LIFEMAX; age++) {
    yangsheng();
    dca();
    code();
}
```
上限交给天，循环体交给自己。到时候是多少年，就是多少年。
